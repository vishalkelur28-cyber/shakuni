# Security Policy

Shakuni runs locally and is built for authorized testing only. If you find a vulnerability in Shakuni's own code, for example a way to reach an API route from outside localhost, or a way to bypass one of the safety gates, please report it privately.

## Reporting a vulnerability

- Preferred: open a private security advisory at https://github.com/vishalkelur28-cyber/shakuni/security/advisories/new
- Include steps to reproduce and the impact.
- Please do not open a public issue for a security vulnerability.

You can expect an initial response within a few days. Thanks for reporting responsibly.

## Scope

This policy covers Shakuni's own code in this repository. It does not authorize testing against any third party. Shakuni is a tool you run against systems you own or are explicitly permitted to test, within a program's scope and rules.
